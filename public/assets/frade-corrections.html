발표와 테스트 문서 정정

  • 발표 26쪽 제목은 “테스트 시나리오 예시”가 맞습니다.
  • 발표 27쪽은 학원 내부망 시연용 주소로 외부 접속이 불가능합니다. 현재 검증한 공개 시연·녹화 링크는 없습니다.
  • 발표 34쪽 “입력하시오.”는 팀 원본의 미작성 칸입니다. 팀원의 평가를 대신 작성하지 않았습니다.
  • 테스트 2쪽 25항: “회원정보 암호화” 대신 “비밀번호 해시값 저장 확인”으로 범위를 한정합니다. 현재 고정 salt·단회 SHA-256을 안전한 비밀번호 저장 성과로 표현하지 않습니다.
  • 테스트 3쪽 50항: ApexCharts가 아닌 Chart.js입니다. 근거: 마이페이지 JSP.
  • 테스트 3쪽 49·52항: 마이페이지는 최근 거래 25건과 해당 목록 건수를 표시합니다. 전체 누적 거래 횟수·누락 없는 전체 이력과 구분합니다. 기간별 조건은 DAO/SQL 구현이며 사용자 화면 필터 완료는 확인하지 않았습니다.
