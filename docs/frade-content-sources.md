## 구현 설명의 대조 기준

확인한 로컬 프로젝트: `D:/workspace/ksm/frade`.

- `PortfolioServiceImpl.java`: 보유종목·예치금·최근 거래 조회, 자산 계산,
  0 분모 처리, 비율 반올림, 초기 투자금 1,000만 원 기준.
- `PortfolioInfoDTO`, `AssetsInfoDTO`, `MyPagePortfolioDTO`: 종목별 계산값과 자산 조회 모델.
- `HistoryDAO`, `history_mapper.xml`: 저장·전체·오늘·최근 일주일·최근 한 달 조회,
  종목명 JOIN 및 정렬 후 ROWNUM으로 최근 25건 조회.
- `portfolio_mapper.xml`: 사용자별 보유수량 0 초과 종목 조회.
- `user/mypage.jsp`: Chart.js 도넛 차트, chart-tick의 가격 검증,
  자산 재계산, 중복 구독 방지, pagehide 정리 및 pageshow 재연결.

테스트 시나리오의 도넛 차트는 ApexCharts로 기재되어 있으나 실제 JSP는 Chart.js를
사용한다. 기술 스택은 실제 구현을 기준으로 유지했다. 테스트 시나리오는 확인 항목이며
모든 테스트가 통과했다는 근거로 사용하지 않았다.

소스의 현재 한계도 상세 설명에 반영했다: 거래 횟수는 최근 조회 목록의 건수,
시세 이벤트는 평가값만 갱신, 예치금·보유수량 변경은 페이지 재조회가 필요하다.
화면의 예시 숫자나 설계 표의 구형 필드 설명보다 현재 소스의 계산을 우선했다.
