## 근거와 버전 경계

- 공개 Provit `5ea207c3eb8d85a074169e89c8efd9b333e27d09`, Frade `a1c49b94ac635e76c5ace60801383c57e584f64e`의 저장소·파일 링크 접근을 확인했다.
- PR #53은 peppyksm 작성·머지된 첨삭 기여 근거다. 모든 기능의 단독 기여는 증명하지 않는다.
- 위 SHA는 링크의 고정 버전이며, 기존 보관 로그의 실행 대상 SHA로 소급하지 않는다.
- 공개본/로컬 검수본 전체 동일성, 운영 DB, 실 API 호출은 별도 확인 대상이다.
- Frade 팀 자료는 원본 보존 + 링크/이미지 옆 정정 및 별도 HTML 정정표 방식이다. 원본 PDF만 개별 전달할 경우 정정표도 함께 전달해야 한다.

## 변경 시 대조 순서

현재 PDF는 웹 디자인에 맞춘 15쪽 버전이다. 이전 13쪽 정정본의 페이지 번호와 구분한다.
`src/data/portfolio.js` → 두 상세 컴포넌트 → 정정표/검증 안내 → `scripts/build_web_portfolio_pdf.py`의 문구를 함께 수정한다.
PDF의 모든 쪽을 렌더하고 추출 텍스트·URI 주석을 확인한다. 기간·인원·역할·스택·한계가 이 표와 일치해야 한다.
