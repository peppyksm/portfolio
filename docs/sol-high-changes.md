## 작업 경계

사용자의 이번 요청에 따라 로컬 포트폴리오를 수정한다. 백엔드 Java·DB·인증·배포·Git push는 포함하지 않는다. 기존 `tmp/audit` 기록은 이번 새 실행 결과로 덮어쓰지 않는다. 팀 산출물 원본은 그대로 보관한다.

## 반영 결과

- Provit: 전체 보관본 조회 오해, requestId·문서 ID/조건 해시, 영구 오류 분류를 웹/PDF에서 정정했다. PDF CRUD 범위·파일 삭제 실패 한계·PROCESSING 복구 부재·학습 참고 점수도 명시했다.
- 문자 길이: 별도 테이블의 기존 검증 기록과 기존 프로젝트 DB 미반영·재배포 필요를 본문으로 드러냈다. 일반 mainDuty 반례는 운영 DDL 미확인 조건부로 남겼다.
- Frade: 기간/5인·담당 DAO/SQL·최근 25건·고정 초기금·가격만 갱신하는 범위를 개인 PDF와 맞췄다. 주문 전체 기여는 추가하지 않았다.
- 팀 발표/테스트/WBS PDF와 DB 이미지 원본은 보존했다. 링크·이미지 옆 정정과 `public/assets/frade-corrections.html`에 식별자/키·총원가·NEXTVAL·차트/해시·전체 이력 범위·제목/내부망/미작성 칸을 명시했다. 원본 PDF를 단독으로 보내면 정정 맥락이 빠지므로 정정표도 함께 전달해야 한다.
- 카드에 대표 사례·코드/PR/검증 링크·현재 이미지 출처를 노출했다. Projects를 첫 화면 다음에 배치하고 메뉴·섹션 순번·스크롤 추적 순서를 함께 맞췄다. 기간/스택/근거 글씨는 12px·#666으로 조정했다(흰 배경 대비 약 5.74:1).
- 재사용한 근거 링크 컴포넌트를 추가했다. 모바일 검수에서 발견한 전역 nav 스타일 충돌은 상단 메뉴로 범위를 제한해 해소했다.
- 개인 PDF 13쪽 구성과 디자인은 유지했다. 기준 원본을 `docs/pdf/`에 보존하고 재생성 스크립트·공통 사실 기준표·README를 추가했다. PDF URI 주석은 4개에서 14개가 됐다.
